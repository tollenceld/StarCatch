# 简体中文截图计划

主截图使用 6.9 英寸 iPhone 模拟器或真机，输出不带透明通道的竖屏 PNG。保留原始截图；如增加标题排版，另存导出文件，不覆盖原图。

推荐顺序：

1. 主天空普通观测：顶部状态、三层星空与统一底部控件。
2. 目标感应/对焦：微型标签、准星和人造目标动态语言。
3. 锁定摘要：底部摘要卡与“查看档案”。
4. 全局星图：三维地球、观察者位置、可见区域与轨道分布。
5. 时间坐标：全局星图时间轴离开 LIVE 的状态。
6. 仪器与隐私：设置中的本地数据、权限状态或隐私摘要。

检查项：

- 截图必须来自实际 App UI，不包含 Xcode 或模拟器窗口边框。
- 不出现调试红框、占位文案、权限弹窗、真实个人位置或临时诊断标签。
- 中文标题不覆盖灵动岛、状态翼、目标或关键遥测。
- 第一张在小尺寸商店列表中仍能辨认“这是卫星观测器”，不依赖长说明。
- 提交前按 Apple 当前截图规格复核像素尺寸与数量。
