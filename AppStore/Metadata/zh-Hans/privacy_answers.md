# App 隐私答卷草案

按当前 1.0 代码与依赖，建议在 App Store Connect 选择：

- 数据收集：**不，我们不会从此 App 收集数据**
- 用于跟踪的数据：无
- 与用户身份关联的数据：无

判断依据：位置、设备姿态、观测记录和偏好只在设备上使用或保存；当前版本没有账号、广告、分析、遥测、崩溃上报或网络上传代码。Apple 的“收集”指将数据从设备传输并允许开发者或第三方在超出实时服务请求所需的时间内访问。

提交前必须重新确认：

- 发布分支没有新增分析、日志上传、远程配置、客服或崩溃 SDK；
- 隐私政策 URL 可公开访问并与应用内文本一致；
- `PrivacyInfo.xcprivacy` 与所有第三方 SDK 的清单仍完整；
- 若未来加入在线目录刷新，仅下载公开轨道数据且不附带设备标识或位置；否则需重新评估答卷。
