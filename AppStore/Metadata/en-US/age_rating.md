# Age Rating draft

The current content is expected to qualify for the lowest age category, subject to the current App Store Connect questionnaire.

- Violence, horror, sexual content, profanity, drugs, gambling: none
- Medical or health information: none
- User-generated content, chat, or public social features: none
- Advertising, purchases, or randomized rewards: none
- Built-in web browser: none; selected support, source, and privacy links open in the system browser
- Location sharing: none; location is used locally for observation calculations
