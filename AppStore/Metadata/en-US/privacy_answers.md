# App Privacy draft

For the current 1.0 code and dependencies, select **No, we do not collect data from this app**.

- Data used to track the user: none
- Data linked to the user: none
- Accounts, advertising, analytics, telemetry, crash upload, and remote configuration: none

Location, device attitude, observation history, and preferences are used or stored only on the device. Recheck the release branch, the public privacy-policy URL, `PrivacyInfo.xcprivacy`, and all dependency privacy manifests before submission.
